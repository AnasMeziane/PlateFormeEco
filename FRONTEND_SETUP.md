# Frontend Setup (React + Tailwind)

## Prérequis
- Node.js 18+
- npm

## Étapes

### 1. Installer les dépendances
```bash
cd frontend
npm install
```

### 2. Lancer le serveur de développement
```bash
npm run dev
```

### 3. Vérification
Le frontend tourne sur : http://localhost:5173

### Pages disponibles
- **Accueil** : http://localhost:5173/
- **Boutique** : http://localhost:5173/shop
- **À Propos** : http://localhost:5173/about
- **Contact** : http://localhost:5173/contact
- **FAQ** : http://localhost:5173/faq
- **Commander** : http://localhost:5173/order
- **Admin Login** : http://localhost:5173/admin/login
- **Dashboard** : http://localhost:5173/admin

### Important
Le backend (php artisan serve) DOIT tourner en même temps sur le port 8000.
